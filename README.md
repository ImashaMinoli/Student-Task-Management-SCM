# Student Task Management

A simple web app for students to add, track and complete their tasks.

## Team Members

| Name | Role |
|------|------|
| Member 1 | Team Lead |
| Member 2 | SCM Lead |
| Member 3 | Reviewer |
| Member 4 | Developer |
| Member 3 | Tester |

## Features

- Add tasks with a due date and priority
- Mark tasks as completed
- Filter by All, Active or Completed
- Tasks are saved in the browser (localStorage)
- On first run, the list is pre-filled from `docs/initial-scm-records.js`
